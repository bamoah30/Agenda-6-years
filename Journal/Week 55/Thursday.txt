Definitions:
- Conditional Statements:
  Programming structures that allow a program to make decisions based on whether a condition is true or false.

- For Loop:
  A loop used when the number of iterations is known beforehand.

- While Loop:
  A loop that continues executing as long as a specified condition remains true.

- Do-While Loop:
  A loop that executes at least once before checking whether the condition is true.

- Frame:
  A coordinate system used to describe the position and orientation of objects in robotics.

- Change of Frame:
  The process of expressing the coordinates of an object relative to a different reference frame.

- Transformation Matrix:
  A matrix used to represent the position and orientation of one frame relative to another.

Work Completed:

Definitions:
- Thevenin's Theorem:
  Any linear electrical circuit can be simplified into an equivalent voltage source in series with an equivalent resistance.

- Norton's Theorem:
  Any linear electrical circuit can be simplified into an equivalent current source in parallel with an equivalent resistance.

Lessons Learned:
1. When finding the Thevenin equivalent of a circuit containing dependent sources, do not turn off the dependent source.
2. Use the test-source method to determine the equivalent resistance when dependent sources are present.
